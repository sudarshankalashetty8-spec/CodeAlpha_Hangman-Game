# Hangman Game – Python

## 📌 About the Project
This Hangman Game is a beginner-friendly Python project developed as part of the **CodeAlpha Python Programming Internship**.
Hangman is a word-guessing game where players try to guess a hidden word by entering one letter at a time. The player has a limited number of incorrect attempts to find the correct word.

## 🎯 Features
- Simple and interactive command-line interface.
- Predefined words for guessing.
- Limited attempts to guess the word.
- Displays correctly guessed letters.
- Tracks incorrect guesses.
- Shows Win or Lose results.

## 🛠️ Technologies Used
- Python 3
- Conditional Statements
- Loops
- Lists
- Strings
- User Input and Output

## ▶️ How to Run
1. Download or clone this repository.
2. Install Python 3.
3. Open the project folder in VS Code or any Python IDE.
4. Run the following command:

```bash
python app.py
```
